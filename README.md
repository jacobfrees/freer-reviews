# freeflow-reviews

Five-star review engine for WordPress: collect reviews on your site, sync Google Business reviews, and follow up by email. GPL open source.

**License:** GNU GPL v2 or later. Free, open source, no subscription, no lock-in — your data stays on your own WordPress site.

## Install

1. Download the latest `freeflow-reviews.zip` from [jacobfrees.com/plugins/freeflow-reviews/](https://jacobfrees.com/plugins/freeflow-reviews/).
2. In WordPress admin go to **Plugins → Add New → Upload Plugin**, upload the zip, then **Install Now** and **Activate**.

## Auto-updates

Plugins distributed here can self-update from [jacobfrees.com](https://jacobfrees.com) over the FreeFlow Plugin Hub update channel.

## Development

- Main plugin file: `freeflow-reviews.php` (folder `freeflow-reviews`).
- Build a distributable zip from the repo root:

```bash
zip -r freeflow-reviews.zip . -x "*.git*"
```
